# FixHYFont – AutoCAD HY 글꼴 깨짐(???) 자동 수정

받은 도면에서 문자스타일 글꼴이 `HY헤드라인M` 대신 `HYHeadLine-Medium`(영문 이름)으로 저장돼 있어서
글자가 `???`로 보이는 문제를 자동으로 고칩니다.

## 파일
| 파일 | 용도 |
|---|---|
| `FixHYFont.lsp` | UTF-8 버전. **AutoCAD 2021 이상** (`LISPSYS` = 1, 기본값) |
| `FixHYFont_ANSI.lsp` | CP949(ANSI) 버전. **AutoCAD 2020 이하** 또는 `LISPSYS` = 0 |

> 한글이 들어간 LISP라 버전에 맞는 파일을 써야 합니다. 로드 후 메시지가 깨져 보이면 다른 쪽 파일을 쓰세요.

## 명령어
| 명령 | 동작 |
|---|---|
| `FIXHYFONT` | 현재 도면의 문자스타일·MTEXT 글꼴을 수정 (실행취소 가능) |
| `FIXHYFONTALL` | 열려 있는 모든 도면 수정 (저장은 직접) |
| `FIXHYFONTBATCH` | 폴더를 고르면 안의 DWG를 일괄 수정·저장 (하위폴더 선택 가능, 원본은 `.bak`로 백업) |

수정 내용:
1. 문자스타일 글꼴 `HYHeadLine-Medium` → `HY헤드라인M` (한글 문자셋으로 지정)
2. MTEXT/다중지시선 안에 직접 지정된 글꼴 코드(`\fHYHeadLine-Medium|...`)도 같이 변경

## 설치 – 도면 열 때마다 자동으로 고치기 (추천)
1. `APPLOAD` 실행
2. 아래쪽 **시작하기 세트(Startup Suite) → 내용** 클릭 → **추가** → `FixHYFont.lsp` 선택
3. 닫기. 이제 도면을 열 때마다 자동으로 수정되고 명령창에 결과가 표시됩니다.

자동 실행을 원하지 않으면 lsp 파일의 `(setq *FixHY-AutoRun* T)`를 `nil`로 바꾸세요.

## 버튼(클릭 한 번)으로 쓰기
`CUI` → 명령 작성 → 매크로에 `^C^CFIXHYFONT` 입력 → 리본/빠른 실행 도구막대에 끌어다 놓기.
(일괄 처리 버튼은 `^C^CFIXHYFONTBATCH`)

## 다른 HY 글꼴도 깨질 때
lsp 상단 `*FixHY-FontMap*`에 `("영문이름" . "한글이름")` 한 줄을 추가하세요.
영문 이름은 문자스타일 대화상자의 글꼴 이름 칸에 보이는 그대로 쓰면 됩니다.
(HY견고딕, HY중고딕 등 예시가 주석으로 들어 있음)

## 참고
- 일괄 처리(ObjectDBX)로 저장한 도면은 파일 탐색기 미리보기 썸네일이 없어질 수 있습니다. 도면을 한 번 열어 저장하면 다시 생깁니다.
- 잠긴 레이어나 읽기전용 파일은 건너뛰고 명령창에 실패로 표시합니다.
- 일괄 처리는 받은 원본 도면을 직접 덮어쓰므로, 원본 폴더 대신 복사본 폴더에서 돌리는 것을 권장합니다.
